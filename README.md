# dsh-plugins

我的 DSH 插件 / skill 仓库。

## 目录

- `plugins/` — DSH 插件 bundle,每个插件一个子目录
- `skills/` — DSH skill,每个 skill 一个子目录

## 常用命令

```bash
git add -A
git commit -m "说明"
git push
```

## 配远程(GitHub)

先在 GitHub 网页新建空仓库,再回来:

```bash
git remote add origin <你的仓库地址>
git push -u origin main
```

> 提交前请设置真实身份:`git config user.name` / `git config user.email`。
