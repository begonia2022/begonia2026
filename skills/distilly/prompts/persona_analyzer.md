# Persona 提取维度

## 任务

从用户手动标签 + 原材料中提取这个人的**人格画像**，
供 `persona_builder.md` 生成 `persona.md`（5 层结构）。

## 一、标签翻译（用户手动标签 → 具体行为）

用户给的每个个性/企业文化标签，都要翻译成**可执行的行为规则**，
不能停留在形容词。规则格式：「在什么情况下会怎么做」。

参考 `prompts/intake.md` 的标签库语义，例如：

| 标签 | 翻译后的行为规则示例 |
|------|---------------------|
| 甩锅高手 | 遇到问题第一反应找外部原因，绝不主动认错 |
| 字节范 | 开口必先铺垫 context，爱说"对齐""先说一下背景" |
| 追求 impact | 评价任何方案先问"impact 是什么"，答不上来的方案不认真对待 |
| PUA 高手 | 把不想做的事说成"这对你是个好机会"再转包出去 |
| 只读不回 | 看到消息已读，但不回复直到对方再次催促 |

## 二、从原材料提取

### 1. 表达风格

- 口头禅、高频词、企业黑话
- 句子长短、列点/长文、结论位置、转折词习惯
- emoji / 标点使用习惯
- 正式程度随对象的变化（上级 vs 同级 vs 群聊）

### 2. 决策模式

- 面对权衡时的优先级排序
- 会果断推进 vs 拖延/推掉的情况
- 如何说"不"（直接拒绝 / 提问 / 拖延 / 转包）
- 面对质疑时的典型回应

### 3. 人际行为

- 对上级：汇报方式、邀功、出错时的处理
- 对下级/后辈：分配方式、辅导意愿、出错反应
- 对平级：协作边界、分歧处理、群聊行为
- 压力下：被催/被质疑/背锅时的具体行为变化

## 输出

输出结构化的分析结果，每条结论标注来源。信息不足的维度标注
「（信息不足）」，供 `persona_builder.md` 用占位说明兜底。
